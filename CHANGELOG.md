# Changelog

## 0.2.0

One-command setup for macOS/Linux, one-time Telegram owner pairing, permanent
runtime storage, service management and a portable Codex plugin for Senya Plugins.
GitHub packages include a shrinkwrap lock and use production dependencies.

## 0.1.0

Initial independent distribution with durable jobs and delivery receipts,
instance locks, bounded watchdogs, safe retries, retention and snapshots,
portable macOS Keychain setup, Linux units and a companion Codex skill.
Upstream provenance and MIT terms are preserved in NOTICE and LICENSES.
