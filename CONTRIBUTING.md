# Contributing

Use Node.js 24 and Python 3.10 or newer. Install local dependencies with
`npm ci`, then run `npm run verify` and `npm run audit:ci`. Add regression
checks for changes to authorization, delivery durability, process lifecycle
or metadata handling. Use synthetic data, never credentials or private logs.

Contributions to original bridge code use BSD-3-Clause. Preserve the MIT
notices for imported upstream code. See NOTICE for provenance.
