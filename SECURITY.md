# Security

This service gives allowlisted Telegram users access to your local Codex
account and selected working directories. Use a dedicated bot, protect the
Telegram account and keep the host approval boundary enabled. Do not expose
state directories, worker sockets, bot tokens or session logs.

Do not put exploit details or credentials into public issues. While this
repository is private, report suspected vulnerabilities directly to its owner
through an existing private communication channel. No public reporting address
or response-time guarantee has been established.

See docs/security-model.md for implemented protections and remaining limits.
